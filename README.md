# WUWA_CHARACTER_OOP

**WUWA_CHARACTER_OOP** — это консольное приложение на C#, созданное для практики объектно-ориентированного программирования (ООП) на основе вселенной игры Wuthering Waves. Проект позволяет создавать персонажей с разными типами оружия, просматривать их характеристики, управлять списком и демонстрирует работу наследования, полиморфизма, инкапсуляции, а также базовые принципы работы с коллекциями и пользовательским вводом.

---

## Функции

| Категория | Описание |
|-----------|----------|
| **Создание персонажа** | Добавление нового персонажа с выбором оружия (`Sword` / `Claymore`), указанием имени, элемента и роли. Все базовые характеристики (HP, ATK, DEF, крит. шанс, крит. урон) задаются константами для упрощения. |
| **Просмотр списка** | Вывод всех созданных персонажей с нумерацией и цветовым выделением. |
| **Детальная информация** | Просмотр полной статистики выбранного персонажа: имя, оружие, элемент, HP, ATK, DEF, крит. шанс, крит. урон, роль, а также специфические параметры (например, скорость атаки для разных типов оружия). |
| **Удаление персонажа** | Удаление персонажа из списка с предварительным отображением его характеристик для подтверждения. |
| **Обработка ошибок** | Валидация пользовательского ввода (проверка на число, диапазон) с цветовыми подсказками (зелёный — успех, красный — ошибка, синий — информация). |

## Что я закрепила на практике

- Наследование — создание иерархии классов (`Character` → `SwordChar`, `ClaymoreChar`);
- Полиморфизм — переопределение виртуальных методов (`GetDamage()`, `PrintStats()`) в классах-наследниках;
- Инкапсуляцию — использование свойств (`get`/`set`) для управления доступом к данным;
- Работу с коллекциями — хранение объектов в `List<T>` и выполнение операций добавления, удаления, поиска;
- Оформление консольного интерфейса — цветовое выделение сообщений (`Console.ForegroundColor`) для улучшения восприятия текста в консоли;
- Структурирование кода — вынесение повторяющейся логики (вывод списка) в отдельный статический метод.
